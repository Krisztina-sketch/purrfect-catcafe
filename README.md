# Purrfect Cat Café Website

## Description
This is a 3-page website for a fictional Cat Café.

## Pages
- Home page: `index.html`
- Menu page: `menu.html`
- Contact page: `contact.html`

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## Notes
Bootstrap is loaded using the official Bootstrap CDN.
Custom styling is written in `style.css`.

## How to Open
Open `index.html` in a browser. The navigation links connect to the Menu and Contact pages.
