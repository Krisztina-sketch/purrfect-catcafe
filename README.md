# Purrfect Cat Café

![Responsive Mockup](assets/images/responsive.png)

## Introduction

Purrfect Cat Café is a responsive website created for cat lovers who enjoy relaxing with a cup of coffee while spending time with friendly rescue cats. The website introduces visitors to the café, provides information about the menu, and offers an easy way to contact the café. The project focuses on creating a clean, welcoming and responsive user experience using HTML, CSS and Bootstrap.

---

# Design

## Colour Scheme

The website uses warm brown and cream colours to create a cosy café atmosphere. White content cards improve readability while maintaining a clean appearance.

## Typography

Arial, Helvetica and sans-serif fonts were used to provide a simple, modern and highly readable design across all devices.

## Layout

Bootstrap's responsive grid system was used throughout the project to ensure the website adapts well to desktop, tablet and mobile devices.

The layout includes:

- Responsive navigation bar
- Hero sections
- Bootstrap cards
- Contact form
- Responsive footer

## User Stories

As a visitor, I want to:

- Learn about the café before visiting.
- Browse the menu quickly and easily.
- Find the café's contact details.
- Send a message using the contact form.
- Navigate easily between pages.
- View the website comfortably on desktop, tablet and mobile devices.

# Deployment

The project was deployed using GitHub Pages.

## Steps

1. Push the project to GitHub.
2. Open the repository.
3. Select **Settings**.
4. Select **Pages**.
5. Under **Source**, choose **Deploy from Branch**.
6. Select the **main** branch.
7. Save the settings.
8. GitHub generates the live website link.
